Compartilhamento de tela em tempo real, direto do navegador.

O GB Screen é um projeto desenvolvido para tornar o compartilhamento de tela simples e acessível, permitindo que pessoas compartilhem sua tela com outros participantes sem depender de um software de desktop dedicado.

A aplicação utiliza tecnologias de comunicação em tempo real para conectar os participantes e transmitir a tela capturada pelo navegador. O projeto foi desenvolvido com foco na integração entre frontend, backend e infraestrutura em nuvem, explorando os desafios envolvidos na construção e publicação de uma aplicação de streaming em tempo real.

✨ Sobre o projeto

A proposta do GB Screen é oferecer uma experiência direta: acessar a aplicação, iniciar o compartilhamento da tela e permitir que outros participantes acompanhem a transmissão.

Mais do que construir uma interface funcional, este projeto representa uma experiência prática com sistemas distribuídos, comunicação em tempo real e integração de serviços hospedados separadamente.

🚀 Funcionalidades

🖥️ Captura e compartilhamento de tela pelo navegador.

📡 Transmissão de mídia em tempo real utilizando LiveKit.

🌐 Aplicação web acessível por meio de uma interface hospedada na nuvem.

🔗 Integração entre frontend, backend e serviço de comunicação em tempo real.

🛠️ Tecnologias e infraestrutura

Frontend: aplicação web hospedada na Vercel.

Backend: API hospedada no Render.

Comunicação em tempo real: LiveKit.

Captura de tela: APIs de mídia do navegador.

Transmissão de mídia: WebRTC, por meio da infraestrutura do LiveKit.

🧠 Desafios técnicos

Durante o desenvolvimento, um dos principais desafios foi integrar corretamente os diferentes componentes da aplicação e diagnosticar falhas na conexão de mídia.

A investigação envolveu análise de erros no console do navegador, autenticação de participantes, geração de tokens de acesso e comunicação entre o backend e o serviço LiveKit.

Esse processo reforçou a importância de compreender o fluxo completo de uma aplicação, desde a interação do usuário até o estabelecimento de uma conexão em tempo real.

🎯 Objetivo

Construir uma aplicação funcional de compartilhamento de tela e aprofundar conhecimentos em desenvolvimento web, integração de APIs, autenticação, infraestrutura em nuvem e comunicação em tempo real.

O GB Screen faz parte da minha jornada como desenvolvedor, na qual busco transformar conceitos técnicos em aplicações reais, enfrentar problemas de implementação e compreender como os diferentes componentes de um sistema trabalham juntos.
